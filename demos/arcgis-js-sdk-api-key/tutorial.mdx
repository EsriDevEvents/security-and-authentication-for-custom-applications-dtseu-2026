In this demo, we will build a small browser app that shows a map with a search widget using the [ArcGIS Maps SDK for JavaScript](https://developers.arcgis.com/javascript/latest/).

## Create the Developer Credential

Now that the app is almost there, create the developer credential in [the ArcGIS portal](https://developers.arcgis.com/documentation/glossary/arcgis-portal/):

1. Click **Content** > **My content** > **New item**
2. Click **Developer credentials**
3. Select **API Key credentials (_For API Key authentication_)**
4. Select **Public application**
5. Select **No item access**
6. Turn on the **Geocoding** privilege
7. Set API key expiration date and add the referrer URL for your app
    - Local development: `http://localhost:<port>/`
    - Published site: `https://<your-site>/`
8. Fill the item info.
9. Review and accept
10. Copy the **API Key**

</Step>

## Caution! 

API keys are easy to abuse, so it is important you only enable privileges you need for your app. Furthermore you should rotate your API Keys every so often to prevent (long term) misuse by others.

While you can limit your effectiveness to referrers, if some one wants to abuse your API Key in, for example, a python script they will still be able to set the correct referrer manually. 

See also the example python script here using the geocoding service with your API Key.
